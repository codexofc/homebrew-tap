# Homebrew tap for Souvenance

```sh
brew install codexofc/tap/souvenance
```

The formula installs the prebuilt `souvenance` binary of the latest
[release](https://github.com/codexofc/souvenance/releases) for macOS (Apple silicon and
Intel) and Linux (x86_64 and aarch64). Then run `souvenance init`.
